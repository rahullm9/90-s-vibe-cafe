# 90's Vibe Cafe 📼☕

Step back into the golden era of synth tunes, analog warmth, and neon dreams! A retro 90s cyber-diner web experience built with React 19, TypeScript, and Vite.

## Features 🚀
- 📼 **Retro Cassette / Vinyl Music Player**: Background audio playback of classic 90s tracks with spinning vinyl animations, timeline seek bar, and volume controls.
- 🏠 **Aesthetic Neon Hero**: Featuring Londrina Shadow typography, 90s cyber-diner styling, and cafe location details.
- 📖 **Client Memories & Polaroid Diary**: Interactive scrapbook with washi tape, polaroid photos, heart reactions, and custom memory submission modal.
- ✍️ **Community Guestbook**: 5-star rating system, tag highlights, and live customer reviews.
- 📱 **Fully Responsive**: Single-line layout for desktop and clean vertical stacking for mobile screens.

## Tech Stack 🛠️
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla CSS with Glassmorphism & Neon Design Tokens
- **Typography**: Google Fonts (Londrina Shadow, Roboto, Outfit, Inter)
